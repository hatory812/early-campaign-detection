学習へ投入されているのは何個か」をディスク上の実データから数え直した記録。

## 5. 既知バグの影響: NFD 正規化漏れ

CLAUDE.md に記載のある Unicode 正規化バグが、今回の計測で実測として確認された。

- ディスク上のファイル名は **NFD**:
  `'35YaşŞartı_TorbaYasaya__2023-03-26_campaign_fulldata.json'`
  (`ş` = `s` + U+0327 結合セディーユ、`Ş` も同様)
- `.py` 中の除外リストのリテラルは **NFC** で書かれている
- 生の文字列比較 `if file_name not in exceptions` が一致せず、**このグラフは除外されないまま
  学習データに入っている**

したがって:

- **意図された構成**: campaign 180 / noncampaign 127 = 307
- **実際の構成**: campaign 181 / noncampaign 127 = **308**

過去の実験結果 (`results/` 配下) はすべてこのグラフを 1 件含んだまま集計されている。
`unicodedata.normalize('NFC', ...)` を挟んでいるのは `plot_degree_histograms.py` だけで、
学習側 4 ファイル (`train_twitter_MPNN.py` / `train_twitter_snapshot.py` /
`precompute_minimized_embeddings.py` / `plot_snapshot_metrics.py`) は未対応。

なお `#Hıdırellez` の `ı` (U+0131) は単一コードポイントなので NFC/NFD で差が出ず、
こちらは正しく除外されている。

## 6. 再現手順

```bash
python3 - <<'EOF'
import json, os
from collections import Counter

D = '/hss01/A.hattori/rww_all_graphs/degree/mid'
labels = json.load(open('/hss01/A.hattori/all_graphs/graph_labels.json'))
exceptions = ['graph_labels', "Gomis_noncampaign_fulldata", "#Hıdırellez_noncampaign_fulldata",
              '35YaşŞartı_TorbaYasaya__2023-03-26_campaign_fulldata', 'Haluk_noncampaign_fulldata',
              '#ErdenTimurSezonu_noncampaign_fulldata', 'Gustavo_noncampaign_fulldata']

files = sorted(f for f in os.listdir(D) if f.endswith('.json'))
used = [(f[:-5], labels[f[:-14]]) for f in files
        if f[:-5] not in exceptions and f[:-14] in labels]
print(len(files), len(used), Counter(l for _, l in used))
EOF
# => 312 308 Counter({1: 181, 0: 127})
```

## 7. 備考

- 本レポートはグラフ**本数**のみを対象とし、|V| / |E| などのグラフサイズ統計は含まない。
  そちらは `run/degree/snapshot_size_report.sh` で t_w ごとに出せる。
- `--classify_news` は既定 0 なので `split_data` のダウンサンプリング経路は通らず、
  308 グラフがそのまま分割される。`--classify_news 1` にすると campaign 数に合わせて
  noncampaign をサンプリングするため上記の数は変わる。
- `graph_labels_campaign.json` (173 件・7 クラス)、`graph_labels_campaign_noise.json`
  (184 件・8 クラス)、`graph_labels_news.json` (75 件) は多値分類用の別ラベルで、
  本レポートの二値分類設定 (`graph_labels.json`) とは母集団が異なる。
